# Third-party code

This repository contains the PhysCoop implementation and an installation
script, not a copy of the base project. The script fetches a pinned commit of
the public H3-DDG repository so that the original code remains subject to its
own repository terms. The ProteinMPNN backbone and quadruplet operator are
provided by that external checkout.

that the absence of a license grants permission to redistribute or reuse it.
